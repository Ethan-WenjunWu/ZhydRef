## 本地路由

统一使用 `/orgs/settings/<slug>`：

| 分组 | 页面 → slug |
|---|---|
| 企业设置 | 企业信息→`company-info`、公司列表→`company-list`、收支账户→`accounts`、支付配置→`payment-config` |
| 组织架构 | 成员/部门→`members`、角色管理→`roles`、菜单管理→`menus`、查看权限→`contact-auth`、资料显示→`contact-display` |
| AI助手 | 基础设置→`ai-basic`、模型参数→`ai-model`、问题库→`ai-questions`、智能体→`ai-agents` |
| 三方集成 | 微信服务号→`wechat-service`、微信小程序→`wechat-mini`、企业微信→`wecom`、钉钉→`dingtalk`、飞书→`feishu`、APP→`app` |
| 操作日志 | 操作日志→`operation-log` |

预览：`npm run dev`，例如 http://localhost:3000/orgs/settings/company-info

## 实现内容

- **系统设置外壳**：顶部导航选中「系统设置」（1440 下位于「更多」内，并高亮），左侧菜单完整复刻（企业设置/组织架构/AI助手/三方集成/操作日志，含嵌套的「通讯录管理」分组），侧栏折叠、分组展开、页签刷新、消息抽屉、水印等沿用现有应用框架。
- **访问页签**：按已访问的设置页累积生成标签，可关闭、切换，「更多」下拉支持刷新/最大化/全屏/新窗口/关闭当前/关闭其他/关闭所有。设置页签栏不再混入工作台标签，与源站一致。
- **页面类型**：
  - 表格页：公司列表、收支账户、支付配置、操作日志，以及问题库/智能体/三方集成列表
  - 表单页：企业信息、AI 基础设置、AI 模型参数
  - 树/权限/编辑器页：成员/部门、角色管理、菜单管理、查看权限、资料显示
  - 集成配置页：微信服务号/小程序、企业微信、钉钉、飞书、APP
- 表单字段、表格列、按钮文案、筛选条件、空状态、分页结构均按源站抓取结果实现。
- 页内交互全部接线：搜索/重置、状态筛选、分页与每页条数、新增/编辑/删除弹窗与抽屉、开关、邀请码复制与刷新、Logo/图片上传预览、CSV 导出、二级菜单切换（企业信息 门户/安全/通知、模型参数 知识库、成员/部门/岗位、三方集成子菜单）、成员/部门/岗位管理、角色新增与成员转移、菜单拖拽/快捷添加/发布、通讯录权限规则、资料显示字段、问题库分类与问题、三方绑定表单、操作日志用户/IP/服务/端口/日期筛选。
